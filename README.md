# cloudphone-pokemon-showdown

This project is a Cloudflare Worker.

## Configuration
- The main entry point is `worker.js`.
- Configuration is managed via `wrangler.toml`.

## Recent Changes
- Migrated from a legacy server implementation to a Cloudflare Worker architecture.
- Replaced `package.json` and legacy server files with `wrangler.toml` and `worker.js`.
- Recent updates include stability fixes and build triggers for the Cloudflare environment.
